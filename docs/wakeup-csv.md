# WakeUp 课程表 CSV 格式说明

参考官方文档：<https://wakeup.fun/doc/import_from_csv.html>

## 格式

固定 7 列，逗号分隔，UTF-8（带 BOM 兼容 Excel）：

```csv
课程名称,星期,开始节数,结束节数,老师,地点,周数
高等数学,1,1,2,张三,逸夫楼101,1-5、7-11单
```

| 列 | 规则 |
| --- | --- |
| 课程名称 | 任意文本 |
| 星期 | 单个数字 1–7（1=周一，7=周日）；同课程多天须拆成多行 |
| 开始节数 / 结束节数 | 单个数字，不能是中文、不能带分隔符 |
| 老师 / 地点 | 可为空但**不能留空**，未知填 `无` |
| 周数 | 周次集合，用中文顿号 `、` 连接多段；支持 `a-b`、`a-b单`、`a-b双` |

## Excel/WPS 日期陷阱

Excel/WPS 打开 CSV 时会把形如 `6-18`、`5-10` 的单元格**自动解析成日期**
（显示为 `2026/6/18`），若在此状态下保存，文件内容会被真正改写。

官方文档第 1 条说明：*"如果输入周数变成日期请不要做任何修改，APP 会自行处理该情况。"*

本项目的 `export_wakeup.py` 采用更稳妥的做法：把**单一区间**改写为语义完全相同的
多段写法，含顿号后 Excel 不再识别为日期：

| 原值 | 改写后 | 等价性 |
| --- | --- | --- |
| `6-18` | `6、7-18` | ∪{6} ∪ [7,18] = [6,18] |
| `6-9` | `6、7-9` | 同上 |
| `13-18` | `13、14-18` | 同上 |
| `5-10、12-16、18` | 不变 | 已含顿号，本就安全 |
| `6-16双` | 不变 | 含"双"，非日期格式 |
| `8` | 不变 | 单个数字非日期 |

实现见 `export_wakeup.py` 的 `anti_excel()`。

## 上课时间需在 App 内设置

CSV 只描述"第几节"，钟点由 WakeUp 的 `课表设置 → 上课时间` 决定。本校节次参考：

```
第1节 08:10   第2节 09:10   第3节 10:10   第4节 11:10
第5节 14:10   第6节 15:10   第7节 16:10   第8节 17:10
第9节 19:10  第10节 20:10  （每节 45 分钟，两节一大节）
```

## 导入方式

1. 将 `课表_<学期>_wakeup.csv` 原文件发送到手机（微信/QQ 传文件）；
2. 在聊天窗口点击该文件 → 选择「用 WakeUp 课程表打开」；
3. 导入完成后在课表页右上角切换课表。

> 不要把文件用 WPS 打开后另存再导入——多一道转换就多一层出错可能；
> 本项目生成的 CSV 已是可直接导入的成品。
